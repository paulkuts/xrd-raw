XRD-конвертер .raw (Thermo ARL X'TRA / ПО WinXRD)  —  портативная папка
=======================================================================

Ничего устанавливать не нужно: внутри лежит свой Python 3.12, matplotlib и openpyxl.
Папку можно целиком скопировать на флешку и запускать на любом Windows x64.
Интернет не нужен — база эталонных фаз лежит внутри папки.

ЗАПУСК
  1. Двойной клик по START.bat  ->  меню, выбираете действие цифрой.
  2. Либо перетащите .raw прямо на convert-raw.bat (быстрая конвертация в данные).

ЧТО УМЕЕТ (меню START.bat, от полного к простому)
  1 - ИДЕНТИФИКАЦИЯ ФАЗ И ЭЛЕМЕНТОВ. Ищет пики, сопоставляет их с базой эталонных
      дифрактограмм, выдаёт: какие фазы есть в образце, какие элементы в них входят,
      какой пик какой фазе принадлежит. Результат: график с подписями фаз (PNG+SVG),
      отчёт .txt, Excel с листами «Пики», «Фазы», «Элементы».
  2 - Пакетно: все .raw из папки input -> всё сразу + идентификация фаз.
  3 - Всё сразу (один файл): .xlsx + .csv + .xy + PNG + SVG, тема графика на выбор.
  4 - Таблица Excel: .raw -> .xlsx (лист «Данные», родная диаграмма Excel на листе
      «График», лист «Сводка» с параметрами съёмки) и .csv рядом.
  5 - Данные для XRD-пакетов: .raw -> .xy (2 колонки: 2theta, интенсивность) и .csv.
      Для HighScore, Match!, DIFFRAC.EVA, FullProf, GSAS-II, Origin.
  6 - Только график: .raw -> PNG + SVG. Тёмная тема для экрана/презентации, светлая для
      печати и диссертации. SVG - векторный, вставляется в Word без потери качества.
  7 - Открыть папку с последним результатом.

КАК РАБОТАЕТ ИДЕНТИФИКАЦИЯ (коротко и без обмана)
  Пик на дифрактограмме - это отражение от кристаллической плоскости (d, ангстрем),
  а не от отдельного элемента. Поэтому определение идёт через фазу:
    - у каждого пика считаются положение 2theta, d по закону Брэгга d = L/(2 sin T),
      высота и полуширина (FWHM);
    - для каждой фазы базы берутся 12 сильнейших линий (d, интенсивность) и ищется
      совпадение с наблюдаемыми пиками в пределах допуска 0.25 градуса;
    - фаза проходит отбор, только если закрыты минимум 2 из 3 её сильнейших линий;
    - считается FOM (0-100): покрытие эталона, покрытие образца, попадание в сильные
      линии, минус штрафы за несовпавшие сильные линии;
    - затем набор пиков жадно объясняется минимальным числом фаз, остаток показывается
      как «не объяснено» (это и есть кандидаты на фазы, которых нет в базе).
  Элементы - производная от фаз: если найдена фаза CaCO3, в образце есть Ca, C, O.
  Количественных процентов нет: это требует полнопрофильного анализа (Rietveld).

ЧЕГО ЖДАТЬ НЕ СТОИТ (ограничения метода)
  - Рентгеновская дифракция даёт ФАЗОВЫЙ состав, не элементный. Точный элементный
    анализ - это XRF или EDX, другой прибор.
  - Аморфные фазы (стёкла, гели, C-S-H) пиков не дают вообще и не определяются.
  - Лёгкие элементы (H, Li, B, C) практически не видны.
  - Перекрытие пиков даёт несколько равноправных кандидатов - смотрите FOM и остаток.
  - Текстурa и предпочтительная ориентация меняют интенсивности.
  - Если образец содержит фазу, которой нет в базе, она попадёт в «не объяснено».

БАЗА ЭТАЛОНОВ (tools\phases_db.json.gz)
  Собрана из открытых источников, ничего лицензионного:
    - COD (Crystallography Open Database, лицензия CC0) - экспериментальные структуры;
    - JARVIS-DFT (NIST, CC BY 4.0) - расчётные структуры, прошедшие по ICSD.
  Паттерны рассчитаны из структур (Cu K-alpha, 5-90 градусов 2theta).
  Сейчас в базе 32 491 фаза: 21 142 экспериментальные структуры из COD и 11 349
  расчётных из JARVIS; отдельно добраны по номерам записей COD гипс, алит C3S,
  белит C2S, C3A, браунмиллерит C4AF и эттрингит - их в общем дампе не было.
  Это НЕ картотека PDF ICDD: она платная, пятилетняя лицензия на одну машину,
  передавать данные из неё нельзя. Метод сравнения тот же, эталоны - свои.
  Если у кафедры есть легальный PDF-2/PDF-4 (обычно ставится с HighScore или
  DIFFRAC.EVA), эталоны можно выгрузить оттуда и подключить отдельной базой.

КУДА ПИШУТСЯ РЕЗУЛЬТАТЫ
  Рядом с исходным файлом .raw. Если файл лежит в input\, результат будет там же.
  Файлы: <имя>.xy, <имя>.csv, <имя>_graph_dark.png/.svg, <имя>_graph_light.png/.svg,
  <имя>_phases_dark.png/.svg (график с фазами), <имя>_phases.txt, <имя>.xlsx

СОСТАВ ПАПКИ
  START.bat        - меню (главный вход)
  convert-raw.bat  - drag&drop конвертация данных без меню
  tools\           - скрипты: menu.py, winxrd2xy.py, plot_xrd.py, xlsx_out.py,
                     peakpick.py (поиск пиков), phases.py (сопоставление с базой),
                     identify.py (пункт 1 целиком), phases_db.json.gz (база эталонов)
  python\          - встроенный Python 3.12 + matplotlib + openpyxl (не удалять)
  input\           - сюда класть .raw файлы
  tmp\             - кэш matplotlib, можно чистить

ЧТО ЭТО ЗА ФОРМАТ .raw
  Родной формат ПО WinXRD (дифрактометр Thermo ARL X'TRA), не картинка и не образ диска.
  Данные лежат записями по 16 байт: int32 интенсивность | int32 служебное | double 2theta.
  Перед блоком - заголовок (0, число_точек, стартовый_угол); парсер находит блок по этой
  сигнатуре, поэтому подходит и для других файлов с этого прибора.
  Шаг углов и анод определяются автоматически; межплоскостное d считается по Cu K-alpha
  (1.5418 A) - если съёмка была на другом аноде, скажите, поправлю.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
  Окно меню не закрывается само после ошибки: текст ошибки остаётся на экране.
  Пришлите этот текст в чат Warden - починим.
