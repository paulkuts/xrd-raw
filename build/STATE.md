## Грабли
- COD режет частые запросы и рвёт TLS; с домашнего IP работает через `curl.exe`, python-urllib часто падает с SSL EOF. Пауза 1.5–3 с, писать файл с `buffering=1`.
- `text=<слово>&format=lst` возвращает список ID — самый надёжный способ найти фазу в COD.
- В PowerShell-строках через ssh ломаются кавычки и `>` — проверочные скрипты класть файлом.
- Рабочую директорию задавать параметром workdir, а не `cd` внутри ssh-команды.
- Текстовые отчёты для Windows — `utf-8-sig`.
- API: `plot_xrd.make()` → (png, svg, meta); `winxrd2xy.write_xy(data, src, out)`; `identify.run()` → (ans, files, txt).
