# xrd-raw — портативный XRD-конвертер и идентификация фаз

Работа с файлами `.raw` рентгеновского дифрактометра **Thermo ARL X'TRA** (ПО WinXRD 2.0):
конвертация в текстовые форматы, графики, **идентификация кристаллических фаз и элементов по пикам**.

Всё работает офлайн: внутри папки свой Python 3.12 и база эталонных дифрактограмм,
интернет и установка пакетов не нужны.

## Быстрый старт (Windows x64)

1. Двойной клик `START.bat` → меню, действие выбирается цифрой.
2. Свои `.raw` класть в `input\`.
3. Результаты появляются рядом с исходником.

| Пункт | Что делает |
|---|---|
| 1 | **Идентификация фаз и элементов**: пики, фазы, график с подписями, `.txt` + `.xlsx` |
| 2 | Пакетно: все `.raw` из `input\` |
| 3 | Всё сразу: `.xlsx` + `.csv` + `.xy` + PNG + SVG + идентификация |
| 4 | Таблица Excel: данные + родная диаграмма + сводка |
| 5 | `.xy` (2θ, интенсивность) + `.csv` для HighScore, Match!, DIFFRAC.EVA, FullProf, GSAS-II, Origin |
| 6 | Только график PNG + SVG (тёмная или светлая тема) |

Без меню: перетащить `.raw` на `convert-raw.bat` — получишь `.xy` и `.csv`.

## Как работает идентификация

Пик — это отражение от кристаллической плоскости `d`, а не от отдельного элемента, поэтому
определение идёт через фазу:

1. Пики: сглаживание, локальные максимумы, prominence, уточнение положения, FWHM.
2. Пересчёт в `d` по закону Брэгга (`Cu Kα`, λ = 1.5418 Å).
3. Сравнение с эталонными наборами `d, I` в пределах 0.25° по 2θ: покрытие эталона,
   покрытие образца, попадание в сильные линии, штраф за пропущенные сильные линии → FOM 0–100.
4. Автоподбор систематического сдвига ±0.40°.
5. Набор пиков жадно объясняется минимальным числом фаз; необъяснённое показывается отдельно.
6. Элементы — производная от найденных фаз.

## База эталонов

`tools/phases_db.json.gz` — **32 491 фаза**: 21 142 экспериментальные структуры из
[COD](https://www.crystallography.net/) (CC0) + 11 349 расчётных из JARVIS-DFT (NIST, CC BY 4.0).
Паттерны рассчитаны из структур (pymatgen, Cu Kα, 5–90° 2θ).

Это **не** картотека PDF ICDD: она платная, лицензия на одну машину, передача данных запрещена.
Метод сравнения тот же, эталоны — из открытых источников. Если у организации есть легальный
PDF-2/PDF-4, эталоны можно выгрузить оттуда и подключить отдельной базой.

## Ограничения метода

- Рентгеновская дифракция даёт **фазовый** состав, не элементный. Точный элементный анализ — XRF/EDX.
- Аморфные фазы (стёкла, гели, C-S-H) пиков не дают и не определяются.
- Лёгкие элементы (H, Li, B, C) практически не видны.
- Количественных процентов нет — для этого нужен полнопрофильный анализ (Rietveld).
- Фазы, которых нет в базе, попадают в раздел «не объяснено».

## Сборка базы (не входит в портатив)

Нужен отдельный venv с `pymatgen`:

```
python -m venv build\venv
build\venv\Scripts\pip install pymatgen

# 1. разбор дампа CIF COD (архив ~3 ГБ) -> cod_phases.jsonl
build\venv\Scripts\python build\build_cod_dump_mp.py --workers 10

# 2. добор отдельных фаз по номерам записей COD -> cod_extra.jsonl
build\venv\Scripts\python build\add_cod_ids.py --ids "1011074 9008366"

# 3. сборка базы с контролем по эталонным линиям -> phases_db.json.gz
build\venv\Scripts\python build\build_db2.py
```

Проверка после установки на новом ПК:

```
python\python.exe build\smoke_test.py
```

## Устройство

```
tools\peakpick.py    поиск пиков (только numpy — scipy в портативе нет)
tools\phases.py      загрузка базы, скоринг фаз, FOM, отчёт
tools\identify.py    .raw → пики → фазы/элементы → txt + xlsx + графики
tools\plot_xrd.py    графики PNG + SVG (тёмная/светлая тема)
tools\xlsx_out.py    Excel: данные, диаграмма, сводка, листы фаз
tools\winxrd2xy.py   разбор формата WinXRD .raw, .xy/.csv
tools\console.py     согласование кодировки вывода с консолью Windows
tools\menu.py        меню START.bat
```

Формат `.raw` WinXRD: блок из N записей по 16 байт (little-endian) —
`int32 интенсивность | int32 служебное | double 2θ`; перед блоком запись-заголовок `(0, N, стартовый угол)`.
